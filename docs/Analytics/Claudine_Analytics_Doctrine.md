# Claudine Analytics Doctrine

## Purpose

Claudine must track the full client journey from attention to booking.

Analytics should help answer:

- where visitors arrive from
- which CTA they click
- where they drop off
- which funnel converts best
- which clinic offers generate strongest intent
- which leads are highest quality

## Core Metrics

### Traffic
- visits
- device type
- referral source
- landing page views

### Engagement
- button clicks
- pricing clicks
- demo interactions
- scroll depth
- form starts

### Conversion
- free consultation submissions
- priority consultation submissions
- booking requests
- success page visits
- funnel completion rate

### Lead Quality
- treatment interest
- appointment intent
- priority users
- booking deposit users
- repeat enquiries

## Future DataAxis Role

DataAxis may later analyse Claudine traffic across:

- campaigns
- clinic funnels
- user behaviour
- conversion drop-offs
- revenue opportunities

## Rule

Analytics must improve decisions without making the user experience intrusive or noisy.
