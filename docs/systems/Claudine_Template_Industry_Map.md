# Claudine Template Industry Map

## Purpose

Claudine supports modular templates for businesses, creators, professionals, organisations, and premium service providers.

The goal is not to build every template immediately.

The goal is to define future expansion lanes clearly.

## Template Rule

Every template must connect to one of three base systems:

- `_base-service`
- `_base-creator`
- `_base-premium`

This prevents Claudine from becoming a messy collection of unrelated websites.

## Build Rule

Only activate templates in phases.

Do not build all industries at once.

Start with master templates, then adapt by industry.
