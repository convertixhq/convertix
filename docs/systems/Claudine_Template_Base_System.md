# Claudine Template Base System

## Purpose

Claudine templates must be built from reusable base systems, not isolated one-off websites.

## Base Template Types

### _base-service

Used for local and service businesses:

- plumber
- electrician
- builder
- salon
- restaurant
- clinic
- therapist
- gas engineer

Core modules:
- service hero
- trust section
- quote request form
- booking CTA
- testimonials
- service areas
- emergency/contact CTA
- final conversion CTA

---

### _base-creator

Used for creators and personal brands:

- creator
- influencer
- artist
- musician
- podcaster
- streamer
- educator
- author
- coach
- fitness professional

Core modules:
- personal brand hero
- social proof
- media showcase
- booking/contact CTA
- newsletter capture
- merch/product section
- event or launch section
- community CTA

---

### _base-premium

Used for luxury or high-value brands:

- premium clinics
- luxury wellness
- high-end creators
- private services
- boutique businesses
- exclusive experiences

Core modules:
- cinematic hero
- premium trust layer
- luxury CTA system
- concierge-style forms
- elegant pricing/offers
- testimonial proof
- private enquiry flow
- high-end final CTA

## Rule

Templates should inherit structure from base systems first.

Only customise:
- copy
- imagery
- services
- colours
- CTAs
- trust signals
- forms

Do not rebuild every template from zero.
