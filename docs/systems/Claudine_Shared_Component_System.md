# Claudine Shared Component System

## Purpose

Claudine templates must reuse shared frontend systems instead of duplicating code across industries.

## Shared Component Philosophy

A single component should support multiple industries through:
- copy changes
- imagery changes
- CTA changes
- styling variants

without rebuilding the structure.

## Shared Systems

### Hero System
Reusable:
- headline
- subheadline
- CTA buttons
- trust badges
- hero imagery

### CTA System
Reusable:
- booking CTA
- callback CTA
- quote CTA
- consultation CTA
- creator CTA

### Form System
Reusable:
- booking forms
- callback forms
- quote forms
- creator enquiry forms
- newsletter forms

### Trust System
Reusable:
- testimonials
- trust badges
- review blocks
- guarantees
- certifications

### Pricing System
Reusable:
- service pricing
- package pricing
- creator offers
- premium consultations

### FAQ System
Reusable:
- business FAQs
- creator FAQs
- booking FAQs
- payment FAQs

### Navigation System
Reusable:
- top navigation
- mobile navigation
- sticky CTA navigation

### Footer System
Reusable:
- business links
- contact info
- policies
- ecosystem links

## Long-Term Goal

The Claudine frontend should behave like a modular website operating system.

Templates should assemble from shared blocks instead of separate disconnected pages.

## Rule

Build reusable systems first.
Customise second.
