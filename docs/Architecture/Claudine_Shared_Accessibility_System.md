# Claudine Shared Accessibility System

## Purpose

Accessibility must be built into every Claudine template, not added later.

## Core Requirements

Every template should support:

- readable contrast
- semantic HTML
- clear labels
- keyboard navigation
- visible focus states
- large touch targets
- mobile-friendly spacing
- reduced cognitive overload

## Template Rules

Forms must have labels.

Buttons must describe the action clearly.

Navigation must be usable on mobile.

Animations must remain subtle.

No section should rely only on colour to communicate meaning.

## Future Accessibility Tools

Claudine may later include:

- accessibility scanner
- adaptive booking modes
- voice navigation
- AI page summaries
- accessibility score reports
- DataAxis accessibility intelligence

## Rule

Accessible systems are better systems.
