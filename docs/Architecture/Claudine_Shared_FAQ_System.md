# Claudine Shared FAQ System

## Purpose

FAQ sections reduce uncertainty and help visitors make decisions confidently.

## FAQ Types

### Service Business FAQs
- service areas
- availability
- emergency calls
- pricing expectations
- quote process

### Clinic / Wellness FAQs
- consultation process
- booking deposits
- treatment suitability
- privacy
- callback expectations

### Creator FAQs
- memberships
- bookings
- digital products
- event access
- community rules

### Professional Service FAQs
- confidentiality
- enquiry process
- timelines
- fees
- next steps

## FAQ Rules

FAQs should be:
- short
- clear
- reassuring
- non-technical
- action-focused

## Accessibility

FAQ sections must support:
- keyboard navigation
- readable headings
- clear spacing
- screen-reader friendly markup

## Rule

FAQs should remove friction before it becomes hesitation.
