# Claudine Shared CTA System

## Purpose

Claudine CTAs must guide visitors toward the correct business action without feeling aggressive.

## Core CTA Types

### Book Consultation
Used for clinics, salons, wellness, therapists, consultants.

### Request Quote
Used for builders, plumbers, electricians, roofers, cleaners, repair services.

### Reserve Table / Make Booking
Used for restaurants, cafes, hotels, private chefs, events.

### Join / Subscribe
Used for creators, influencers, podcasters, educators, authors.

### Contact / Enquire
Used for lawyers, consultants, agencies, professional services.

## CTA Rules

Every CTA should be:

- clear
- specific
- action-based
- mobile-friendly
- visually premium
- consistent across pages

Avoid vague CTAs like:

- Learn More
- Click Here
- Submit

## Mobile CTA System

Mobile pages may use a sticky CTA when conversion value is high.

Examples:

- Book Consultation
- Request Quote
- Reserve Appointment
- Join Waitlist

## Rule

A CTA should make the next step obvious without pressuring the user.
