# Claudine Shared Navigation System

## Purpose

Navigation must feel calm, premium, clear, and consistent across all Claudine templates.

Visitors should never feel lost or overwhelmed.

## Core Navigation Types

### Desktop Navigation
- logo
- primary links
- CTA button
- clean spacing
- premium layout

### Mobile Navigation
- burger menu
- touch-friendly links
- smooth open/close transitions
- outside-click closing
- sticky CTA support

### Sticky Navigation
Used for:
- booking-heavy pages
- creator launches
- premium consultations
- event-driven pages

## Shared Navigation Elements

Reusable elements:
- logo system
- CTA buttons
- mobile menu
- ecosystem links
- footer navigation
- legal links

## Accessibility Rules

Navigation must support:
- keyboard navigation
- readable contrast
- large touch targets
- clear focus states
- semantic structure

## Rule

Navigation should reduce friction, not create visual noise.
