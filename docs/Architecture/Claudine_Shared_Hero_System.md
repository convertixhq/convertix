# Claudine Shared Hero System

## Purpose

The hero section is the first trust and conversion moment.

It must immediately explain:

- who the page is for
- what problem is solved
- what action the visitor should take
- why the brand feels trustworthy

## Core Hero Types

### Service Business Hero
For trades, restaurants, local services, salons, clinics.

Primary CTA examples:
- Request Quote
- Book Consultation
- Reserve Table
- Check Availability

### Creator Hero
For creators, artists, musicians, authors, streamers, educators.

Primary CTA examples:
- Join Newsletter
- Book Session
- Watch Latest
- Support Launch

### Premium Hero
For luxury clinics, high-end services, private experiences.

Primary CTA examples:
- Request Private Consultation
- Join Waitlist
- Book Premium Appointment

## Hero Rules

Every hero should include:

- strong headline
- clear subheadline
- one primary CTA
- optional secondary CTA
- trust badges or micro-proof
- calm visual hierarchy

## Rule

A hero should create clarity within 5 seconds.
