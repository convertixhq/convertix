# Claudine Shared Form System

## Purpose

Claudine forms must be reusable across industries.

The same form system should support:
- clinic consultations
- service quotes
- restaurant enquiries
- creator bookings
- law firm enquiries
- event requests
- newsletter capture

## Core Form Types

### Callback Form
Used when a business wants to contact the visitor later.

### Quote Request Form
Used by trades and service businesses.

### Booking Request Form
Used by clinics, salons, consultants, restaurants, creators, and events.

### Priority Enquiry Form
Used for high-intent or paid enquiry flows.

### Newsletter / Audience Capture Form
Used by creators, influencers, artists, authors, educators, and brands.

## Required Fields

Every form should support:
- full name
- email
- phone
- enquiry type
- message or request details
- hidden form type

## Future Fields

Optional:
- preferred date
- service area
- budget range
- business type
- urgency level
- referral source
- consent checkbox

## Accessibility Rules

Forms must have:
- clear labels
- large touch targets
- readable placeholders
- keyboard support
- visible focus states
- calm spacing
- screen-reader friendly structure

## Conversion Rules

Forms should feel:
- short
- premium
- trustworthy
- easy
- calm

Do not overload users with unnecessary fields.

## Rule

One reusable form system should power many industries.
